# Larvey IntelliJ Plugin

Install `larvey-syntax-highlighter-plugin-1.0-SNAPSHOT.zip` via Settings > Plugins > Gear icon > Install Plugin from Disk. Requires IntelliJ 2025.2 or newer.

Gives `.larvey` files syntax highlighting with a customizable color scheme, real lexer/parser error checking, keyword and function completion, `${...}` variable completion with Ctrl-click navigation, brace matching, and `//` plus `/* */` commenting.
